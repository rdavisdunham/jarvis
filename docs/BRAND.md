# Eridani production mark

Batch C selects the soft-square peeling-note concept (v19) as the production base: a lavender paper outline, folded corner and three separated pastel stars. It keeps the established wordmark and Orbit interface.

The hand-authored vector is `apps/web/public/icon.svg`; `BrandMark` uses the same geometry in the app and login. `icon-monochrome.svg` uses currentColor. PNG PWA assets are rendered from the vector with a safe margin and opaque background; the source SVG stays resolution independent. Generated concept rasters remain references, not runtime dependencies.

Check at 16/32/192/512 px in light and dark contexts. The celestial motif is a brand reference, not a scientific diagram or claim about every star named Eridani.
